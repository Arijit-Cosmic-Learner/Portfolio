This is a **sample draft**. Drafts only appear when you run the site locally, never in production.

## How to add an article

1. Create a new `.md` file in `content/writing/`.
2. Add the front matter block at the top (title, date, summary, tags).
3. Set `draft: false` (or remove the line) when you're ready to publish.
4. Deploy. The article appears on the Writing page automatically.

Standard Markdown works: headings, lists, links, `inline code`, and

> blockquotes for the lines you want to stand out.
